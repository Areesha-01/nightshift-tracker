# User Stories — NightShift

## Authentication
- As a user, I want to register an account, so that I can access the tracker.
- As a user, I want to log in securely, so that my data stays protected.

## Task Management
- As a team member, I want to create a task, so that work can be tracked.
- As a team member, I want to assign a task to someone, so that responsibility is clear.
- As a team member, I want to edit a task, so that details stay accurate.
- As a team member, I want to delete a task, so that irrelevant items are removed.

## Status Columns
- As a team member, I want to move tasks between To Do, In Progress, and Done, so that progress is visible to the whole team.

## Comments
- As a team member, I want to comment on a task, so that discussion stays attached to the relevant work.
